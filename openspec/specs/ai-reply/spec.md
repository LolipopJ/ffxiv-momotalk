# ai-reply Specification

## Purpose

为 MomoTalk 私聊与群聊会话提供基于 OpenAI 兼容接口的 AI 回复选项生成能力，支持配置管理、上下文组装、按会话隔离的内存选项面板与一键直发交互。

## Requirements

### Requirement: OpenAI 兼容 LLM 配置、风格预设、对话示例与连通性测试
插件 SHALL 持久化保存 LLM 端点、API 密钥、模型名称、当前风格预设标识、自定义系统提示词与自定义结构化对话示例以及聊天上下文窗口配置（时间窗口分钟数默认 `10`、最大条数默认 `100`、最小条数默认 `5`）；当且仅当端点、密钥与模型名称去除首尾空白后均非空时判定 AI 回复功能已配置。插件同时 SHALL 默认提供自然日常 FFXIV 聊天风格、自动匹配近期对话语言的内置预设，允许玩家在预设与自定义模式间自由切换、复制预设到自定义，并支持在不阻塞主线程的前提下测试当前配置端点的连通性。

#### Scenario: 端点、密钥与模型均非空时启用配置
- **WHEN** 玩家在设置中填写非空的端点、密钥与模型名称
- **THEN** AI 回复功能处于已配置状态，允许在聊天界面展示与使用生成入口及测试端点连通性

#### Scenario: 任一必填项为空或仅含空白时视为未配置
- **WHEN** 端点、密钥或模型名称中任意一项为空或仅包含空白字符
- **THEN** AI 回复功能处于未配置状态，不在聊天界面展示生成入口并自动清理残留 AI 状态

#### Scenario: 切换风格预设、编辑自定义提示词示例与上下文窗口
- **WHEN** 玩家在设置中切换风格预设、在 `custom` 模式编辑自定义系统提示词或结构化对话示例、触发复制预设到自定义，或修改时间窗口/上下限参数
- **THEN** 修改后的配置即时持久化保存并按各自边界钳制（最小条数不超过最大条数），且内置预设与 `custom` 模式的配置状态保持相互独立

#### Scenario: 测试已配置端点的连通性
- **WHEN** 玩家在配置完整时触发端点连通性测试
- **THEN** 插件在后台向规范化后的 `/chat/completions` 发起轻量校验请求并返回包含往返耗时的成功结果或经过密钥脱敏的明确错误信息

### Requirement: 内置风格预设、结构化对话示例与配置版本迁移
插件 SHALL 内置默认日常（`default`）、蔚蓝档案 Sensei（`sensei`）及可靠、狡诈、睿智、高冷、活泼五种酒馆 Roleplay（`tavern-reliable`、`tavern-cunning`、`tavern-wise`、`tavern-aloof`、`tavern-cheerful`）共七套纯英文风格预设与配套结构化对话示例，并支持独立的 `custom` 模式、一键复制到自定义、将有效示例内嵌于系统提示词以及从 v1 配置安全备份升级至 v2。

#### Scenario: 切换内置风格预设并保持自定义内容独立
- **WHEN** 玩家在风格选项列表（`custom` 与七套内置英文预设）间切换当前风格
- **THEN** 选中内置预设时使用该预设只读的纯英文系统提示词与纯英文结构化对话示例（其中 `sensei` 包含 10 组、其余内置预设各包含 5 组情境，每组均附带 3 条不同角度的单行回复）；切回 `custom` 时使用支持任意语言文本的自定义提示词与自定义结构化对话示例（每组含情境文本与 1 至 3 条单行候选回复），来回切换预设不会覆盖或丢失 `custom` 中已保存的内容

#### Scenario: 将当前预设复制到自定义
- **WHEN** 玩家当前选中任一内置预设并触发复制预设到自定义操作
- **THEN** 插件将该预设的系统提示词与全部结构化对话示例深拷贝并覆盖写入 `custom` 模式配置、立即持久化保存，并将当前选中风格切换为 `custom`

#### Scenario: 结构化对话示例嵌入系统提示词且遵循实时聊天语言
- **WHEN** 当前有效风格包含至少一条有效结构化对话示例（情境文本非空白且含 1 至 3 条非空白单行候选回复）并触发回复生成
- **THEN** 插件保持 `[system, user]` 双消息请求结构，将有效示例序列化为 `{"replies":[...]}` 目标 JSON 块内嵌于系统提示词中，并显式声明示例仅用于示范语气与角度多样性、实际回复 MUST 匹配近期对话所使用的语言；缺少有效情境或无有效回复的空白示例将被跳过

#### Scenario: 从已发布 v1 配置安全升级至 v2
- **WHEN** 插件加载已存在的 v1 配置文件，或遇到未知/高于支持版本的配置文件
- **THEN** 升级 v1 前先在配置目录创建不覆盖既有备份的本地备份文件，保留既有端点、密钥、模型、界面语言、展示开关与上下文窗口参数，将未改动默认提示词的 `LlmPrompt` 映射为 `default` 预设、将改动过的 `LlmPrompt` 映射为 `custom` 并完整保留原提示词文本且原子写入 v2 配置；若版本未知或升级任一步骤失败，则保留原配置文件不被覆盖、记录含数据域与失败步骤的错误日志并允许后续重试

### Requirement: AI 请求传输与错误脱敏
插件 SHALL 对远程端点使用 HTTPS，仅允许回环端点使用 HTTP。连通性测试与回复生成均 SHALL 禁止自动跟随重定向。显示服务端错误预览前 SHALL 先遮盖 API 密钥，再截断文本；HTTP 失败日志 SHALL 仅记录状态码和本地错误摘要。

#### Scenario: 拒绝远程 HTTP 端点
- **WHEN** 玩家配置非回环的 HTTP 端点并测试连接或生成回复
- **THEN** 插件提示远程端点需要 HTTPS，且不发送请求

#### Scenario: 端点返回重定向
- **WHEN** 配置端点返回 HTTP 重定向
- **THEN** 插件按失败处理该响应，且不向重定向地址发送请求

#### Scenario: 服务端错误中包含 API 密钥
- **WHEN** 服务端错误中含有 API 密钥并且密钥跨过预览截断位置
- **THEN** 界面只显示遮盖后的预览，日志只包含状态码和本地错误摘要

### Requirement: 聊天上下文组装与后台异步生成
插件 SHALL 在不阻塞游戏主线程的前提下于后台异步读取当前会话历史消息并请求 OpenAI 兼容 `/chat/completions` 接口（兼容自动补全请求路径），结合当前会话频道信息、备注、当前时间、按可配置时间窗口与条数上下限（默认最近 10 分钟、最多 100 条、最少 5 条）筛选的带时间戳消息及「当前有效风格提示词 + 有效结构化对话示例（若有） + 系统固定格式约束」生成 1 至 3 条单行合规回复选项。

#### Scenario: 按可配置时间窗口与条数上下限组装带时间戳上下文
- **WHEN** 玩家在已有历史消息的私聊或群聊会话中触发生成回复
- **THEN** 插件优先保留最近配置分钟数内的消息（不超过最大条数上限），当时间窗口内消息少于最小条数时按时间倒序补足至最小条数，并附带每条消息本地时间戳、发言者名称（本人/他人区分）、频道类型与备注发送至模型，生成 1 至 3 条自然日常且匹配近期对话语言的回复选项

#### Scenario: 空会话触发生成开场白选项
- **WHEN** 玩家在尚无历史消息的会话中触发生成回复
- **THEN** 插件向模型提供当前会话对象与频道信息，生成 1 至 3 条适合打招呼的开场回复选项

#### Scenario: 无有效对话示例时仅拼装风格提示词与格式约束
- **WHEN** 当前选中的 `custom` 模式尚未添加任何有效结构化对话示例并触发生成回复
- **THEN** 插件仅将有效风格提示词与系统固定格式约束组装进系统提示词，不输出空的示例章节

#### Scenario: 自动兼容 Base URL 与完整请求地址
- **WHEN** 玩家配置的端点为服务根地址或已包含 `/chat/completions` 的完整地址
- **THEN** 插件自动规范化为有效的 `/chat/completions` 请求地址发起调用

#### Scenario: 服务端明确拒绝输出格式参数
- **WHEN** 服务端返回 HTTP 400 或 422 并明确指出不支持 `response_format`
- **THEN** 插件移除该参数后重试一次。其他请求错误直接返回，不触发降级重试

#### Scenario: 从非标准成功响应中提取候选项
- **WHEN** 服务端成功返回包含代码块、编号或额外换行的响应内容
- **THEN** 插件以兼容规则提取 1 至 3 条纯文本候选项，不要求用户提示词自行维护输出格式

#### Scenario: 过滤非法与超长条目并在无有效结果或请求异常时报错
- **WHEN** 模型返回包含换行、控制字符、空内容或加上当前频道命令前缀后超过游戏 500 字节 UTF-8 上限的候选项，或发生网络、鉴权或超时异常
- **THEN** 插件清洗并过滤非法或超长候选项；若最终无有效选项或请求失败，向当前会话返回明确错误提示

### Requirement: 回复选项内存生命周期与防重控制
插件 SHALL 仅在内存中按会话隔离保存 AI 回复选项面板与在途生成状态而不写入本地聊天历史库；每次触发生成前先移除当前会话既有面板并在生成完成或异常前禁止重复触发，切换登录角色或卸载插件时取消全部在途请求并清空内存面板。

#### Scenario: 生成期间禁止重复触发并在结束或异常后恢复
- **WHEN** 玩家点击生成按钮发起当前会话的回复生成请求
- **THEN** 插件先移除该会话既有选项面板并锁定生成触发，直至本次生成完成或异常结束后才允许再次触发

#### Scenario: 不同会话的选项状态相互独立
- **WHEN** 玩家在会话 A 生成选项或等待生成期间切换至会话 B
- **THEN** 会话 B 不会展示或覆盖会话 A 的选项面板与生成状态，切回会话 A 时仍保留该会话对应状态

#### Scenario: 切换角色或卸载插件清理在途请求与面板
- **WHEN** 玩家切换当前登录角色或卸载插件
- **THEN** 插件取消所有未完成的后台生成请求并清空全部内存选项面板

### Requirement: 选项直发与手动发信自动移除面板
插件 SHALL 允许玩家点击任一 AI 回复选项将其直接发送至当前会话频道并移除面板，或忽略选项直接手动发送消息并在发送后自动移除既有选项面板；当前会话处于不可发送状态时禁止触发生成。

#### Scenario: 点击回复选项直接发送到当前频道
- **WHEN** 玩家点击选项面板中的任一回复选项且当前会话可发送
- **THEN** 插件立即向当前频道提交该条真实消息并移除该会话的选项面板

#### Scenario: 未点击选项而从插件输入框手动发送新消息
- **WHEN** 当前会话展示着 AI 回复选项面板，玩家未点击任何选项而在输入框中输入新内容并成功提交发送
- **THEN** 插件正常发出该条新消息并立即移除当前会话的选项面板

#### Scenario: 从游戏原生聊天框向同会话发信后同步移除面板
- **WHEN** 当前会话展示着 AI 回复选项面板且插件采集到玩家从游戏原生聊天框向该会话发出的出站消息回显
- **THEN** 插件立即移除该会话的选项面板

#### Scenario: 不可发送会话禁止触发生成
- **WHEN** 当前会话因好友名单未加载、已退出部队或通讯贝、或固定队成员不匹配而处于不可发送状态
- **THEN** 插件禁止触发 AI 回复生成并维持既有不可发送状态提示
