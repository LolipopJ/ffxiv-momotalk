# Proposal

## Why

希望在国际服游戏内按好友查看私聊历史，并从同一个窗口回复。以好友私聊作为首版，可以先交付从发起对话到实际收发、保存和回看的完整流程。

## What Changes

- 新增一个受 MomoTalk 启发的游戏内双栏窗口。会话列表支持按完整名称的首字母与最近消息时间排序，并可从已读取的游戏好友名单发起私聊。
- 在选定会话中输入并手动发送消息。插件通过游戏原生聊天接口向对应好友提交真正的 `/tell`，从游戏私聊事件读取收发消息。
- 将同一好友的收发消息归入同一会话，按当前登录角色在本地保存和分页读取历史。
- 会话列表显示好友的 Lodestone 头像，聊天气泡显示实际发言者的 Lodestone 头像。暂时无法获取头像时显示占位图。

## Capabilities

### New Capabilities

- `friend-private-chat`: 游戏好友私聊的会话管理、实际发送、消息归档及玩家头像。

### Modified Capabilities

## Impact

- 国际服 Dalamud API 15 插件，涉及游戏聊天事件、好友名单与原生聊天输入。
- 在插件内提供 ImGui 前端和本地 SQLite 历史。头像服务按需查询公开 Lodestone 数据。
