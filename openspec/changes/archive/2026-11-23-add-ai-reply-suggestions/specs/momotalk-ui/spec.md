# Spec Delta

## ADDED Requirements

### Requirement: 聊天栏 AI 回复生成按钮
插件 SHALL 当且仅当设置中 `Endpoint`、`API Key` 与 `Model` 均非空时，在聊天输入栏发送按钮左侧显示 AI 回复生成矢量图标按钮；未配置完整时隐藏该按钮并保持原有输入框宽度，在当前会话不可发送或正处于生成中状态时禁用该按钮。

#### Scenario: 未配置完整 LLM 信息时隐藏按钮
- **WHEN** 设置中的端点、密钥或模型名称任一项为空或仅含空白
- **THEN** 发送按钮左侧不显示 AI 回复生成按钮，聊天输入框保持既有铺满布局

#### Scenario: 配置完整后在发送按钮左侧显示图标按钮
- **WHEN** 设置中的端点、密钥与模型名称均非空，且当前会话可发送并处于空闲状态
- **THEN** 发送按钮左侧显示可点击的 AI 回复生成图标按钮

#### Scenario: 生成中或不可发送时禁用按钮
- **WHEN** 当前会话正在等待 AI 回复生成完成，或当前会话处于不可发送状态
- **THEN** AI 回复生成按钮保持可见（已配置时）但呈现禁用状态，点击不会触发重复或无效请求

### Requirement: 对话流 MomoTalk 风格回复选项卡片
插件 SHALL 在对话流底部（位于输入中三点脉冲气泡上方）以全英文 UI 呈现参考 `u1805/momotalk` 风格的 `Reply` 卡片：浅灰蓝圆角底与细边框、右上角矢量淡蓝几何三角纹理、左侧蓝色竖条与 `Reply` 标题、横分割线及 1 至 3 个全宽居中白底圆角微阴影按钮，并在生成中展示加载占位卡片、生成失败时沿用输入框上方系统警告灰条提示。

#### Scenario: 生成期间在对话流底部展示加载占位卡片
- **WHEN** 玩家点击 AI 回复生成按钮发起当前会话的生成请求
- **THEN** 对话流立即移除当前会话既有 `Reply` 卡片并在底部显示同风格的加载占位卡片

#### Scenario: 生成完成后渲染 1 至 3 个 MomoTalk 风格回复选项按钮
- **WHEN** 后台成功生成 1 至 3 条有效回复选项
- **THEN** 对话流底部展示带右上几何三角纹理、蓝竖条 `Reply` 标题、分割线与居中白底圆角微阴影选项按钮的回复卡片，悬停与按压有明确视觉反馈且对话流在处于底部时自动跟随显示

#### Scenario: 点击选项发送或手动发送后移除卡片
- **WHEN** 玩家点击卡片中的任一回复选项按钮直接发送，或在未点击任何选项的情况下手动发送新消息（含游戏原生聊天框发送的同会话消息）
- **THEN** 该 `Reply` 卡片立即从当前会话对话流移除；再次点击生成按钮时亦先移除旧卡片

#### Scenario: 生成失败时展示系统警告灰条
- **WHEN** 生成请求发生异常或未产出有效回复选项
- **THEN** 加载占位卡片移除，输入框上方以系统警告灰条展示错误原因，且生成按钮恢复可点击状态

## MODIFIED Requirements

### Requirement: MomoTalk 风格设置弹窗与配置持久化
插件 SHALL 在珊瑚粉顶栏关闭按钮左侧提供设置齿轮按钮，点击后于主窗口内带打开/关闭过渡动画叠加显示参考 `u1805/momotalk` 风格的半透明遮罩与居中白底圆角设置弹窗，通过顶部 `General` 与 `AI Reply` 双标签页分别提供常规开关（全局入口、入场动画与本人右侧头像）与 OpenAI 兼容配置（端点、可切换显隐的 API 密钥、模型、`Test Connection` 端点连通性测试与状态横幅、`Chat Context` 时间窗口/最大/最小条数设置、多行系统提示词及 `Reset to Default`），为设置页按钮提供清晰的鼠标悬浮、按压与手型指针反馈，在窄窗口下保持可滚动操作并持久化配置；在 Dalamud 中点击「设置」时自动打开主窗口并展开设置弹窗。

#### Scenario: 通过顶栏齿轮开关配置并立即生效
- **WHEN** 玩家点击顶栏齿轮打开设置弹窗并在 `General` 标签页切换 `Show Floating Entry`、`Show Intro Animation` 或 `Show Self Avatar` 开关
- **THEN** 对应配置立即保存至插件配置文件，全局入口与本人右侧头像的显示状态实时响应，下一次打开主窗口按最新入场动画配置执行

#### Scenario: 通过 Dalamud 设置入口直达设置弹窗
- **WHEN** 玩家在 Dalamud 插件列表中点击本插件的「设置」按钮
- **THEN** 插件打开并将 MomoTalk 主窗口置前，同时自动展开设置弹窗；点击遮罩空白处、弹窗关闭按钮或按下 ESC 可关闭设置弹窗而不关闭主窗口

#### Scenario: 在 AI Reply 标签页配置 LLM、测试连通性并切换密钥显隐
- **WHEN** 玩家在设置弹窗顶部切换至 `AI Reply` 标签页，填写或修改 `Endpoint`、`API Key` 与 `Model`，切换密钥显隐控制或点击 `Test Connection`
- **THEN** 密钥默认以掩码隐藏并支持明文与掩码间切换，全部字段修改立即持久化并重置过期测试状态，点击 `Test Connection` 在按钮禁用态完成后于下方展示成功延时横幅或警告错误横幅，聊天栏 AI 生成按钮随配置完整性实时显示或隐藏

#### Scenario: 在 AI Reply 标签页配置上下文窗口、系统提示词与按钮交互反馈
- **WHEN** 玩家在 `AI Reply` 标签页调整 `Chat Context`（`Minutes` / `Max` / `Min`）、修改 `System Prompt`、点击 `Reset to Default`，或鼠标悬浮与点击页内按钮
- **THEN** 上下文窗口参数与自定义提示词即时保存至配置，点击 `Reset to Default` 后立即还原默认提示词，且设置页内可点击按钮与标签页展示明确的高亮边框、背景切换、按压下沉与手型光标反馈

#### Scenario: 最小窗口尺寸下保持设置页面完整可编辑
- **WHEN** 玩家在最小窗口尺寸下打开设置弹窗并切换至内容较高的 `AI Reply` 标签页
- **THEN** 设置弹窗自动限制高度并支持内部区域滚动，所有输入框与 `Reset to Default` 按钮均可正常触达与编辑
