# Proposal

## Why

当前的插件窗口仅采用浅粉配色的标准 ImGui 双栏框架与下拉框新建会话，与《蔚蓝档案》MomoTalk 标志性的视觉层次和交互节奏差距较大。基于 [u1805/momotalk](https://u1805.github.io/momotalk/) 的视觉语言忠实还原窗口外壳、双 Tab 导航、列表排布与气泡对话体验，同时保持与 FFXIV 真实好友 Tell 流程的语义契合，能显著提升辨识度与日常私聊效率。

## What Changes

- 将标准 ImGui 窗口框架替换为自绘无原生标题栏的 MomoTalk 外壳：珊瑚粉顶栏（矢量 Momo Logo、粗体标题、可拖动区与关闭按钮）、左侧深灰蓝导航条、冰灰列表栏与纯白右侧画布，并实现窄窗口下的底部导航与单栏返回回退。
- 用左侧导航条的「联系人」与「会话」双 Tab 替换现有的“新建会话”下拉框，彻底移除网页版对话生成器专属控件（底栏工具、发言人切换条、回复/羁绊卡片、传图及副主题设置等）。
- 为列表栏增加顶部胶囊搜索框与 `-15deg` 斜切排序按钮；列表行按左侧圆形头像、中部角色名与副标题（会话 Tab 显示最近消息预览）、右侧服务器名称排布。
- 为「联系人」Tab 增加右侧好友资料卡（居中大圆头像、右下角发起对话快捷按钮、角色名与服务器胶囊），点击快捷按钮或双击好友行进入对应会话。
- 重绘纯白聊天画布：对方深灰蓝左尖角气泡与本人蓝色右尖角气泡、同发言者连续消息合并、保留右侧本人 Lodestone 头像、按时间间隔插入居中浅灰胶囊时间条（气泡悬浮显示精确时间）、拒发原因改用 MomoTalk System message 圆角灰条样式，以及底部浅灰胶囊输入栏与发送按钮。

## Capabilities

### New Capabilities

- `momotalk-ui`: 基于 u1805/momotalk 视觉风格还原的 MomoTalk 游戏内界面外壳、联系人/会话双导航、好友资料卡、列表检索排序、气泡分组与时间/拒发系统条及窄屏响应式布局。

### Modified Capabilities

## Impact

- 主要影响 `src/FFXIVMomoTalk/Windows/` 下的窗口与视觉绘制实现（`MomoTalkWindow.cs`、`ChatVisuals.cs` 及拆分出的 UI 绘制模块）。
- 复用现有好友快照、Tell 收发、SQLite 本地历史与 Lodestone 头像缓存，不修改数据库表结构与消息采集/发送契约。
- 严格遵循 `openspec/changes/add-friend-private-chat` 已定义的实时收发、排序、历史分页、双方头像与拒发归属行为。
