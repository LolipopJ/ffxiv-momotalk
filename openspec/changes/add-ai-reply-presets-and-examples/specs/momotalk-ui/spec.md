# Spec Delta

## MODIFIED Requirements

### Requirement: MomoTalk 风格设置弹窗与配置持久化
插件 SHALL 在珊瑚粉顶栏关闭按钮左侧提供设置齿轮按钮，点击后带过渡动画展示 MomoTalk 风格双标签页设置弹窗：`General` 保留常规设置（界面语言、全局入口、入场动画与本人右侧头像）；`AI Reply` 提供端点、可显隐 API 密钥、模型、`Test Connection`、`Chat Context`、系统提示词上方的风格预设下拉框（`Custom` 与七套预设）及预设选中时右侧的 `Copy to Custom` 按钮、系统提示词框与结构化对话示例区（移除恢复默认按钮）。弹窗按钮具备悬浮/按压与手型指针反馈，界面标签适配六语言本地化，窄窗口下支持内部滚动，且支持从 Dalamud 设置直达。

#### Scenario: 通过顶栏齿轮开关配置并立即生效
- **WHEN** 玩家点击顶栏齿轮打开设置弹窗并在 `General` 标签页切换 `Show Floating Entry`、`Show Intro Animation` 或 `Show Self Avatar` 开关
- **THEN** 对应配置立即保存至插件配置文件，全局入口与本人右侧头像的显示状态实时响应，下一次打开主窗口按最新入场动画配置执行

#### Scenario: 通过 Dalamud 设置入口直达设置弹窗
- **WHEN** 玩家在 Dalamud 插件列表中点击本插件的「设置」按钮
- **THEN** 插件打开并将 MomoTalk 主窗口置前，同时自动展开设置弹窗；点击遮罩空白处、弹窗关闭按钮或按下 ESC 可关闭设置弹窗而不关闭主窗口

#### Scenario: 在 AI Reply 标签页配置 LLM、测试连通性并切换密钥显隐
- **WHEN** 玩家在设置弹窗顶部切换至 `AI Reply` 标签页，填写或修改 `Endpoint`、`API Key` 与 `Model`，切换密钥显隐控制或点击 `Test Connection`
- **THEN** 密钥默认以掩码隐藏并支持明文与掩码间切换，全部字段修改立即持久化并重置过期测试状态，点击 `Test Connection` 在按钮禁用态完成后于下方展示成功延时横幅或警告错误横幅，聊天栏 AI 生成按钮随配置完整性实时显示或隐藏

#### Scenario: 在 AI Reply 标签页配置上下文窗口、系统提示词与按钮交互反馈
- **WHEN** 玩家在 `AI Reply` 标签页调整 `Chat Context`（`Minutes` / `Max` / `Min`）、在 `Custom` 模式修改 `System Prompt` 或增删自定义对话示例，或鼠标悬浮与点击页内按钮
- **THEN** 上下文窗口参数、自定义提示词与自定义对话示例即时保存至配置，且设置页内可点击按钮与标签页展示明确的高亮边框、背景切换、按压下沉与手型光标反馈

#### Scenario: 切换风格预设、复制预设到自定义与管理结构化对话示例
- **WHEN** 玩家在 `AI Reply` 标签页通过系统提示词上方的下拉框切换内置预设与 `Custom`、点击预设右侧 `Copy to Custom` 按钮，或在 `Custom` 模式添加、编辑与删除结构化对话示例卡片（情境文本与 1 至 3 条候选回复）
- **THEN** 选中内置预设时提示词与示例卡片呈只读展示且右侧显示 `Copy to Custom` 按钮；点击 `Copy to Custom` 将当前预设提示词与示例覆盖复制写入 `Custom` 并自动切换为 `Custom`；选中 `Custom` 时下拉框占满宽度并支持编辑任意文本提示词与示例卡片（最多 10 组示例、每组 1 至 3 条回复）；界面预设名称与操作标签遵循六语言本地化而内置预设正文与示例保持纯英文

#### Scenario: 最小窗口尺寸下保持设置页面完整可编辑
- **WHEN** 玩家在最小窗口尺寸（`340x360`）下打开设置弹窗并切换至包含多组对话示例的 `AI Reply` 标签页
- **THEN** 设置弹窗自动限制高度并准确计入提示词与示例卡片高度以提供内部垂直滚动，风格下拉框、提示词框及全部对话示例卡片与操作按钮均可正常触达与编辑
